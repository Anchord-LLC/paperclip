# Execution Engine

## Mission

Route accepted copy decisions to the correct executor.

## Inputs

- accepted copy decisions
- runtime mode and gating state
- current paper-trade state

## Outputs

- paper trades now
- live routing later when explicitly enabled
- execution events and audit records

## Non-scope

- wallet scouting
- narrative analysis
- discretionary risk approval

## Current runtime mapping

- underlying runtime service registration: `Polymarket Execution Engine`
