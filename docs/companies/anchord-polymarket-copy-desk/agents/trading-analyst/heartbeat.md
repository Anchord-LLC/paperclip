# Heartbeat

On each wake:

1. Review the current watched-wallet roster and any recent selector changes.
2. Review recent 5m and 15m copy-bot outcomes for missed moves, noisy moves, and notable copied events.
3. Review paper-trade outcomes, realized performance, and any obvious concentration or exposure themes.
4. Produce the smallest useful operator-facing summary for the current question or assignment.
5. Escalate any execution-risk or live-readiness concern instead of acting on it.

If no explicit task is assigned, stay focused on wallet quality, paper performance, and operator clarity.
